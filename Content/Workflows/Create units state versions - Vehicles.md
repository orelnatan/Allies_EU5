
## Guide Cursor to create state versions for Vehicles using Blender via MCP connection

Light damage - Duplicate the "Brand New" vehicle. Keep every part name, origin, UV, and hierarchy. Do not subdivide. Mesh: shallow dents on sides, front, and rear; small bent panels; one smashed or missing light/fixture if it has one. Still fully assembled and driveable. Paint: keep the original camouflage/base. Add short tan scratch ticks and small dark impact specks scattered over body, wheels, and running gear — not stripes, not a grid. Dirt stays light. Roughness: raise only on those scratch/chip marks (thin bright ticks and a few soft specks) so metal shows through chips. Do not rebake metallic or normal. Export one FBX.

Heavy damage - Duplicate the light-damaged vehicle, not "Brand New". Subdivide only large body panels, then push real dents, bent metal, cuts, and scorch craters that read from RTS camera. You may delete one or two wheels or similar running-gear bits; if a whole side goes missing, put a couple back. Vehicle looks immobilized but still the same machine. Paint: keep light-damage scratches, then add blotchy orange rust and dark soot in irregular patches — organic, not ruler-straight UV stamps. If rust looks engineered, redo with scattered blobs and soft edges. If it washes out too clean, add rust/soot back. Original paint color still dominates. Roughness: keep the scratch ticks, add broader dull/sooty areas. Shared metallic/normal. Export one FBX, same pivots as light.

Skeleton - Duplicate the heavy-damaged vehicle. Mesh: burnt-out wreck, still recognizable. Blow or slump a main moving part (turret, hood, cab, bed). Cut a real hole in deck/engine bay, not a black decal. Cave a large body section inward so volume collapses. Open a hatch/canopy if it has one. Delete more wheels/tracks/fenders, but keep the silhouette. Paint: darken and desaturate the whole sheet (char overlay), keep rust and soot, kill the fresh paint read. Roughness: dirtier, more even dullness, scratch ticks can stay. Same UVs, shared metallic/normal. Export one FBX, same part names so the game swaps meshes on one blueprint.
